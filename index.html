Awesome AI Local Tools 1000 是什麼？

它是一個以瀏覽器本地推論為核心的 AI 工具集合，涵蓋文字、圖像、音訊與多模態應用，強調不依賴雲端 API 也能完成主要工作。

這些 AI 工具需要把資料傳到伺服器嗎？

首頁描述的主要方向是本地執行與隱私優先。多數工具會盡量把處理留在使用者裝置端，降低資料外傳風險。

這個專案適合誰？

它適合想找可直接試用的本地 AI 工具，也適合研究 WebGPU、WASM、ONNX Runtime Web 與前端 AI 產品設計的開發者。
